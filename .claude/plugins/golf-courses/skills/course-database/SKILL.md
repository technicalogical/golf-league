## Data Integration Notes

### For Database Schema

Recommended database tables:

**courses**
- id (primary key)
- name
- location
- architect
- year_opened
- par_total
- par_out
- par_in
- course_record (nullable)
- major_championships (text, nullable)

**tee_boxes**
- id (primary key)
- course_id (foreign key)
- tee_color (Black/Gold/Blue/White/Red)
- rating_men (decimal, nullable)
- slope_men (integer, nullable)
- rating_women (decimal, nullable)
- slope_women (integer, nullable)
- drive_distance (varchar, e.g., ">275 yards")

**holes**
- id (primary key)
- course_id (foreign key)
- hole_number (1-18)
- par
- handicap_men
- handicap_women

**hole_yardages**
- id (primary key)
- hole_id (foreign key)
- tee_color
- yardage

### Tee Box Selection Guide

- **Black**: Championship/Professional (>275 yard drives)
- **Gold**: Advanced (250-275 yards)
- **Blue**: Intermediate (225-249 yards)
- **White**: Average (200-224 yards)
- **Red**: Beginner/Senior (<200 yards)

### Special Course Notes

- **Harbour Town**: Par 71 (not 72)
- **Texas Golf Tour**: Par 71 (not 72)
- **The Infamous 18**: Par 69 with a Par 6 hole (#18)!
- **The New Course at St Andrews**: Par 71 (not 72)
- **Wildstone**: Par 72 but 37 out, 35 in (not 36/36)

### Implementation Recommendations

1. **Course Selection**: Allow league admins to select courses from the database
2. **Tee Box Assignment**: Match players to appropriate tees based on skill/driving distance
3. **Handicap Calculation**: Use course rating/slope for proper handicapping
4. **Scorecards**: Display hole-by-hole yardages from selected tee
5. **Stroke Allocation**: Use handicap column for match play stroke allocation
6. **Statistics**: Track performance by course, by tee box, by hole difficulty
